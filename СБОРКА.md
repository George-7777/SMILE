1. В корне приложения (app/src/main/java/com/gvayt/smile) создайте java-класс Secret.java

Он должен содержать единственную константу с ключом от api Vertex AI, но на время защиты проекта для экономии времени проверяющих я оставлю свой ключ здесь. Содержимое класса:
```java
package com.gvayt.smile;

public class Secret {
    public final String keyAI = "AQ.Ab8RN6L7mtFLSh-V9kCG254uf-b928hjTylSspQEKJZKcpk1bg";
}
```
2. В той же папке в файле Constant.java вместо значения константы BASE_URL поставьте свой IP-адресс сервера:
```java
// API
public static final String BASE_URL = "http://10.36.122.1:8080/"; // Введите свой адрес сервера
  ```
3. После этого можете собирать приложение. Предварительно не забудьте развернуть ![сервер](https://github.com/George-7777/SMILE-BACKEND)
